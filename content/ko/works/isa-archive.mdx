## 개요

ISA Archive는 단순한 비주얼 쇼케이스가 아닌 **UI 아키텍처 실천 프로젝트**입니다.
페이지를 직접 디자인하는 대신, 구조화된 데이터로부터 이력서, 작업 내역, 아카이브 항목을 렌더링할 수 있는 재사용 가능한 UI 프리미티브 시스템으로 구축되었습니다.

임의의 페이지 디자인 대신 **컴포넌트 계약과 레이아웃 일관성**을 최우선으로 둘 때 개인 사이트가 장기적으로 얼마나 높은 유지보수성을 가질 수 있는지 탐구합니다.

---

## UI 아키텍처 접근법

### 컴포넌트 우선 합성 (Component-First Composition)

모든 UI 요소는 페이지로 조립되기 전 Storybook을 통해 격리된 상태에서 개발 및 검증됩니다. 페이지는 순수한 합성 레이어로 기능하며 라우트 레벨의 레이아웃 로직을 포함하지 않습니다.

- 콘텐츠 변화에도 UI 동작의 예측 가능성 유지
- 레이아웃 수정이 무관한 다른 섹션으로 전파되지 않음
- 이력서, 작업, 아카이브 뷰 전반에 걸친 컴포넌트 재사용

---

### 시스템 경계로서의 스타일링

Styled Components를 활용하여 컴포넌트 레벨에서 엄격한 스타일 경계를 강제합니다:
- 전역 CSS나 계단식 사이드 이펙트에 의존하지 않음
- 레이아웃, 여백, 타이포그래피는 컴포넌트 자체의 공개 계약의 일부로 관리
- 중앙 집중형 테마 설정을 통한 시각적 일관성 유지

---

### 데이터 비종속적 UI 렌더링

Contentlayer를 사용하여 이력서와 작업 항목에 대한 타입 스키마를 정의했습니다.
UI 컴포넌트는 페이지별 props 대신 정규화된 데이터 형태를 소비합니다.

- 동일한 컴포넌트가 다양한 콘텐츠 밀도를 유연하게 렌더링
- 이력서와 작업 뷰가 중복 없이 동일한 UI 로직 공유
- UI 레이어와 무관하게 콘텐츠 구조 독립적 확장 가능

---

## 결과

ISA Archive는 **UI 아키텍처 주도 개발 방식**을 입증하는 대표적인 작업입니다.
페이지가 아닌 컴포넌트를 기본 설계 단위로 삼음으로써 UI 복잡도를 높이지 않고도 지속적으로 확장 가능한 플랫폼을 완성했습니다.
