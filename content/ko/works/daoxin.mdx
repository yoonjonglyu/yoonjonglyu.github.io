## 개요

**ABILITY DaoXin (道心)**은 단순한 일정 관리 도구가 아닌, 코드로 구현된 철학입니다.

외부 성취의 결과는 본질적으로 가변적이고 시간이 지나면 증발하기 마련입니다. 이 프로젝트는 _"모든 외적인 것이 사라졌을 때 끝까지 남는 것은 무엇인가?"_라는 질문에서 출발했습니다. 그 해답은 바로 내면의 마음과 꺾이지 않는 의지—즉 **도심(道心)**입니다.

하지만 인간의 의지는 본래 연약하여 의식적인 일상 행동의 반복을 통해서만 유지되고 축적될 수 있습니다. 프로젝트 DaoXin은 사용자의 추상적인 노력과 정진을 모듈화하고 시각화하여, 영적 성장의 구체적인 기록으로 치환해주는 **'경험 중심 제품'**입니다.

---

## 문제 정의

기존의 습관 트래커와 플래너 소프트웨어는 주로 다음 3가지 한계로 인해 실패합니다:

1. **차갑고 딱딱한 체크리스트**: 기능 위주의 무미건조한 대시보드로 인해 자기계발이 마음 챙김이 아닌 피로한 숙제처럼 느껴짐.
2. **몰입감 있는 서사의 부재**: 단순히 체크박스를 누르는 행위에 내적 동기나 의미가 결여되어 장기적 지속성이 급격히 감퇴함.
3. **분절된 작업 흐름**: 일일 습관, 중기 목표, 상위 분류가 제각각 분리되어 노력의 연속성이 단절됨.

이를 해결하기 위해 이 프로젝트는 **"꾸준한 루틴을 동양의 수양 예술로 번역한다"**는 결론을 내렸습니다.

## 아키텍처 전략

### 1. 몰입형 '선협 수양' 컨셉

- **체크리스트를 넘어선 정진**: 루틴의 일관성을 통해 내면의 '기운(Qi)'을 축적하고 상위 경지로 돌파합니다. 실천이 끊기면 다시 '범부(Mortal)'로 남게 됩니다.
- **3원적 코어 인프라**:
  - **메인 뷰**: 중앙 '도심' 상태 지표와 당일 즉각적인 다짐 요약 노출
  - **카테고리 뷰**: 무공 영역처럼 사용자의 노력을 분류하고 자체 통계 메트릭으로 환산
  - **스케줄 뷰**: 단기 루틴과 영구적 장기 워크플로우를 관장하는 코어 스케줄러

### 2. 코어 종속 데이터 아키텍처

- **계층적 종속 데이터 트리**: 모든 워크플로우와 하위 카테고리는 최상위 '도심' 코어 상태의 직속 하위 요소로 설계
- **단방향 데이터 무결성**: TypeScript 유니온 타입으로 강제되어 하위 태스크 완료가 즉각 상위 진행 지표로 정밀하게 반영

### 3. 제로 오버헤드 바닐라 CSS

- 런타임 CSS-in-JS 라이브러리를 배제하고 순수 **Vanilla CSS** 적용
- 모바일 웹뷰 환경에서도 프레임 드랍 없는 60fps 렌더링 보장

### 4. Jotai를 통한 원자적 상태 분리

- 전역 컨텍스트를 작은 단위의 아톰(`daoxinStateAtom`, `categoryStatsAtom`)으로 격리
- 스케줄 변경 시 다른 레이아웃 요소의 불필요한 리렌더링 원천 차단

## 기술적 결정

- **React & Functional Hooks**: 명확한 컴포넌트 경계와 아토믹 로직 캡슐화
- **Jotai**: 바텀업 상태 조합과 파생 계산에 최적화된 경량 상태 관리
- **Vanilla CSS**: 제로 런타임 스타일링과 장기적 코드 지속성 확보
- **Capacitor**: 표준 웹 아키텍처를 네이티브 앱 생태계로 부드럽게 패키징
