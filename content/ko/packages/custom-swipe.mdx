## 배경

기존의 주요 스와이프 라이브러리들은 다양한 기능을 제공하지만 번들 사이즈가 크고, 디자인 커스터마이징 시 기존 프로젝트의 스타일과 잦은 충돌을 일으켰습니다.  
특히 저사양 모바일 기기나 네트워크 환경이 취약한 상황에서도 매끄럽게 동작할 수 있는 **경량 스와이프 솔루션**이 절실했습니다.  
이를 해결하기 위해 스와이프의 핵심 인터랙션은 완벽히 관리하되, UI 스타일링은 전적으로 개발자에게 위임하는 'Headless' 구조의 라이브러리를 기획 및 개발했습니다.

## 해결한 문제

- **프레임워크 종속성 탈피**: 스와이프 핵심 로직을 특정 프레임워크에 종속되지 않는 비제어(Uncontrolled) DOM 조작 계층으로 분리하여 React, Vue, Svelte 등 어떤 환경에서도 동일하게 동작하도록 구현했습니다.
- **번들 사이즈 최적화**: 무한 스크롤, 캐러셀 등 꼭 필요한 핵심 스와이프 기능에만 집중하여 대체 라이브러리 대비 월등히 가벼운 용량을 달성했습니다.
- **자유로운 UI 커스터마이징**: 특정 마크업이나 인라인 스타일을 강제하지 않는 Headless Hook 방식을 제공하여, 개발자가 사내 디자인 시스템에 맞춰 스와이프 UI를 자유롭게 구성할 수 있도록 지원했습니다.

## 기술적 선택 근거

- **Headless Architecture**: UI 표현 계층과 비즈니스 로직을 완벽히 분리하여 재사용성을 극대화하고 다양한 디자인 요구사항에 유연하게 대응하기 위해 채택했습니다.
- **TypeScript**: 라이브러리 사용자에게 명확한 타입 정의와 안정성을 제공하여, 복잡한 제스처 이벤트 처리 중 발생할 수 있는 런타임 오류를 방지하고 개발자 경험(DX)을 향상시켰습니다.
- **Multi-Package (Monorepo)**: 모노레포 구조를 도입하여 단일 코어 로직 소스를 유지하면서 각 프레임워크별 래퍼 패키지(React, Vue, Svelte)를 효율적으로 관리하고 배포할 수 있도록 구성했습니다.
- **Vanilla DOM API**: 가상 DOM이나 리렌더링 사이클의 오버헤드를 배제하고, 밀리초 단위의 정확한 제스처 감지와 부드러운 60fps 애니메이션을 보장하기 위해 네이티브 DOM API를 직접 활용했습니다.

## 🚀 주요 기능

1. **Swipe**: 기본 수평/수직 제스처 감지 및 터치 추적
2. **Infinite Swipe**: 끊김 없는 무한 스크롤 루프 지원
3. **Carousel / Slider**: 직관적인 슬라이더 및 인덱스 제어
4. **Headless Hook**: 상태와 제어 함수를 프로그래밍 방식으로 제공
