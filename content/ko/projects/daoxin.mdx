# 🛠️ daoxin: 기술적 엄밀성과 원자적 아키텍처

**풍부한 은유 구조를 갖춘 경량 크로스플랫폼 애플리케이션의 참조 모델**

`daoxin` 프로젝트는 "추상적인 인간의 의지와 누적되는 일관성을 어떻게 하면 가장 가볍고 견고한 데이터 구조로 박제할 수 있는가?"라는 근본적인 프론트엔드 아키텍처적 질문에 답하는 구조적 참조 모델입니다.

무거운 엔터프라이즈급 전역 상태 도구를 과감히 배제하고 **React**와 **Jotai**를 도입하여 바텀업(Bottom-up) 원자 단위의 상태 관리를 실현했습니다. 스타일링 레이어에서는 외부 추상화 라이브러리의 런타임 오버헤드를 걷어내고 브라우저 표준인 **순수 CSS(Vanilla CSS)**를 사용하여 스타일링 예측 가능성을 확보했으며, **Capacitor** 런타임을 통해 고성능 하이브리드 크로스플랫폼 파이프라인을 구축했습니다.

핵심 아키텍처 기둥은 다음과 같습니다:

- **Jotai 기반의 원자적 데이터 모델링**: 거대한 단일 상태 트리를 탈피하여 독립적인 상태 노드(Atoms) 단위로 스케줄 및 분석 데이터셋 관리.
- **하위 종속형 데이터 구조 설계**: 다중 스케줄 레이어와 카테고리 통계 모듈이 최상위 룰인 '도심(道心)' 코어 시스템에 엄격하게 종속되는 계층 구조 확립.
- **순수 CSS 기반의 제로 오버헤드 스타일링**: 런타임 스타일 연산이나 전처리 빌드 오버헤드가 전혀 없는 완전한 웹 표준 스타일 생태계 구축.
- **Capacitor 하이브리드 최적화**: 성능 손실 없이 웹 기술을 모바일 네이티브 생태계로 패키징하는 파이프라인 구축.

## 기술적 도전 과제 및 아키텍처 전략

### 1. 제로 오버헤드 고성능을 위한 Pure CSS
디지털 수묵화 비주얼, 실크 질감 레이어, 전통 무협 타이포그래피 등 정취 깊은 동양적 아이덴티티를 구현하기 위해 브라우저 네이티브 Vanilla CSS에 전적으로 의존했습니다.
- CSS-in-JS의 런타임 연산 비용을 제거하고 복잡한 전처리 빌드 과정을 걷어내어 프론트엔드의 구조적 단순성을 극대화했습니다.
- 브라우저의 네이티브 렌더링 엔진을 직접 활용하여 모바일 웹뷰 환경에서도 프레임 드랍 없는 부드러운 60fps 렌더링을 보장합니다.

### 2. 3개 페이지 상태 분리 및 바운디드 컨텍스트
- **메인 뷰 (도심 코어 & 스케줄 요약)**: 중앙 컨트롤 허브로서 파생(Derived) Atom을 활용해 내면의 도심 카운터와 요약 스케줄을 초기 렌더링 병목 없이 효율적으로 결합합니다.
- **카테고리 뷰 (분류 & 통계)**: 일상 루틴을 무공 분파처럼 분류하고 로우 데이터를 다차원 통계 차트로 환산하는 연산 로직을 캡슐화합니다.
- **스케줄 뷰 (멀티 스케줄러 엔진)**: 단기 일일 루틴부터 장기 목표까지 독립적인 워크플로우를 등록, 모니터링, 정리하는 스케줄러 레이아웃입니다.

### 3. 코어 종속형 데이터 아키텍처 (3원적 계층)
모든 하위 스케줄러와 분류 구조를 단 하나의 신뢰 원천인 사용자의 내면 상태 **"도심(道心)"**에 직속 종속시켰습니다. 이 계층 구조는 TypeScript 유니온 인터페이스를 통해 강제되어 단방향 데이터 흐름을 완벽히 보장합니다.
