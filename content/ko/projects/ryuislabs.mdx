# 🌐 RyuisLabs: 딥테크 인디 스튜디오 웹 플랫폼

> *"모든 성취의 이면에는, 치열한 과정이 존재합니다."*  
> *"우연에 기대지 않습니다. 비즈니스의 성공도, 시스템의 구동도 모두 설계된 인과의 결과입니다."*

**RyuisLabs(류이즈랩스)**는 온디바이스 AI 비전과 제로 지식(Zero-Knowledge) 원칙 기반의 프라이버시 보존형 상태 검증 엔진인 **`RYUis : STATUS`**를 비롯하여, 독창적인 제품군(ABILITY 시리즈, MemoFlow, SeedVault 등)의 비즈니스와 기술 명세를 체계적으로 소개하는 공식 엔지니어링 웹 플랫폼입니다.

개인 포트폴리오의 가벼운 인상을 배제하고, 시스템 청사진(Blueprint)을 마주하는 듯한 묵직한 신뢰감과 절차적 정당성을 전달하도록 설계되었습니다.

---

## 프로젝트 배경 및 브랜드 정체성

기술 인디 스튜디오로서 RyuisLabs는 단순한 앱 개발을 넘어 **"인간의 숙련과 몰입을 객관적인 데이터로 입증하는 기술"**을 연구합니다.

- **The Blueprint Aesthetics**: 딥 다크(`bg-zinc-950`)와 엔지니어링 도면 그리드 라인을 결합하여 기술적 정밀함을 시각화
- **절차적 정당성**: 감성적 과장이나 홍보성 미사를 배제하고, 시스템 구조와 인과관계에 기반한 명확한 기술 문서 톤앤매너 유지
- **글로벌 스케일**: 국내뿐 아니라 영미권, 일본, 중화권 파트너십을 위해 기획 단계부터 4개 국어(한국어, 영어, 일본어, 번체 중국어) 서브패스 SSG 아키텍처 구축

## 핵심 비즈니스 모델 및 시스템 라인업

### 1. 플래그십 시스템: `RYUis : STATUS`
온디바이스 AI 비전을 통해 시선과 관절 동작을 감지하여 사용자의 몰입과 신체 훈련을 객관적으로 입증하는 프라이버시 보존형 상태창:
- **MODULE_01 / FOCUS_VISION**: 시선 추적(Eye Tracking) 기반 순수 몰입 시간(Pure Focus Time) 산출
- **MODULE_02 / PHYSICAL_VISION**: Pose Estimation 기반 관절 각도 정밀 카운팅 및 훈련 검증
- **MODULE_03 / ZERO_KNOWLEDGE_LOG**: 원본 카메라 영상은 온디바이스 연산 즉시 파기, 암호화된 통계 벡터 데이터만 보존
- **비즈니스 티어**: B2C(개인 몰입/훈련 검증), B2B2C(학부모/코치 검증 리포트), B2B(스터디카페/피트니스 센터용 SDK 라이선스)

### 2. 프로덕트 쇼케이스 카탈로그
- **ABILITY Series**:
  - `ABILITY: Gravity & Time`: SF 중력 테마의 몰입형 타이머 (Wakelock, 네이티브 알람)
  - `ABILITY: DaoXin (도심)`: 동양 수양 철학 기반의 원자적 일상 루틴 트래커 (React, Jotai, 순수 CSS)
- **Standalone Utilities**:
  - `MemoFlow`: 즉각적인 생각 정리를 위한 오프라인 우선 PWA 플래너
  - `SeedVault`: Argon2id + AES-256-GCM 기반 로컬 제로 지식 암호화 금고

## 프론트엔드 아키텍처 및 구현 특징

### 1. URL 서브패스 기반 정적 라우팅 i18n (`/[lang]/...`)
- Next.js 16 App Router의 `generateStaticParams()`를 통해 4개 국어(KO, EN, JA, ZH-TW)의 모든 라우트를 빌드 시점에 100% 정적 사전 렌더링(SSG)
- 미들웨어를 통해 `Accept-Language` 헤더 기반 언어 자동 감지 및 서브패스 리다이렉트 지원

### 2. 제로 런타임 오버헤드 스타일링
- Tailwind CSS 4와 전용 CSS Modules(`*.module.css`)를 조화롭게 사용하여 전역 스타일 오염을 방지하고 극상의 렌더링 성능 확보
- 모바일 뷰포트(`420px`) 압축 브레이크포인트를 정밀하게 설계하여 모바일 환경에서도 도면 레이아웃의 완성도 유지

### 3. 고도화된 접근성 & 모션 제어
- `prefers-reduced-motion` 미디어 쿼리를 감지하여 모션 감소 옵션 활성화 시 터미널 부팅 타이핑 효과를 스킵하고 즉각 콘텐츠 표시
- 경량화된 `IntersectionObserver` 기반 Reveal 컴포넌트로 부드러운 스크롤 페이드인 연출
