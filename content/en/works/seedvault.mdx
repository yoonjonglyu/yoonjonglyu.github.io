## Overview

**SeedVault** is an **on-device, zero-knowledge mobile security vault application** designed to operate entirely offline without servers, cloud synchronization, or network dependencies.

Decrypted exclusively via the user's master password and biometric hardware authentication, it isolates and secures cryptocurrency mnemonic seed phrases, private keys, and sensitive account credentials using military-grade encryption algorithms.

---

## Project Background & Pivot

### 1. Discontinuation of SeedWallet due to Regulatory Hurdles
Originally, the project began as **SeedWallet**, a comprehensive cryptocurrency wallet solution encompassing blockchain transactions and asset custody. However, the project encountered substantial non-technical regulatory barriers—including global Virtual Asset Service Provider (VASP) regulations, licensing compliance, and legal liabilities surrounding custodial operations.

### 2. Identifying Core Value & The Spin-Off
Rather than discarding the work, focus was redirected entirely to the most essential part of the wallet engine: **"providing users with the most secure, verifiable method to store private keys and seed phrases without relying on any third-party server."**
- Completely excised transaction broadcasting and network communication modules
- Extracted the cryptographic core (`@seedvault/crypto-core`) and redesigned the UI into a dedicated security vault app
- **Officially published on the Google Play Store (`com.ryuislabs.seedvault`)**

---

## Core Security Architecture

### 1. Argon2id Memory-Hard Key Derivation (KDF)
Standard SHA-256 or basic PBKDF2 implementations are susceptible to high-throughput GPU/ASIC brute-force attacks. SeedVault utilizes WebAssembly-optimized **Argon2id** to derive encryption keys from master passwords.
- Configured time cost, memory cost, and parallelism parameters to achieve maximum resistance against brute-force and side-channel threats within mobile constraints

### 2. AES-256-GCM Authenticated Envelope Encryption
To safeguard both confidentiality and data integrity, SeedVault implements **AES-256-GCM**.
- Packages encrypted credentials into an envelope format (`EncryptedSeedEnvelope`) containing unique salts, initialization vectors (IV), and authentication tags to detect any local tampering

### 3. Absolute Zero-Knowledge & Local-First Design
- **No Backend, No Cloud**: Contains no API client, requiring no network permissions and executing 100% of cryptographic operations on-device
- **Secure Hardware Keystore**: Integrates Capacitor Secure Storage and Native Biometric plugins for convenient fingerprint/Face ID unlock without exposing master keys

### 4. Air-Gapped QR Backup & Recovery Pipeline
Facilitates completely offline data backups and device-to-device transfers:
- Vault payloads are compressed with Zlib (`pako`) and encoded in Base64
- Generates high-density QR codes (`qrcode`) and enables camera-based restoration (`jsqr`) in completely air-gapped environments
