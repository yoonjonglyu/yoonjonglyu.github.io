# 🔐 SeedVault: オンデバイス・ゼロ知識暗号化セキュリティ金庫

> *"サーバーを信じるな。数学と自分の端末のみを信じよ。"*  
> *"法的規制によりウォレット開発が止まった時、我々は核心となるセキュリティ技術を切り離し世に送り出しました。"*

**SeedVault**は、暗号資産のシードフレーズ（Mnemonic Seed Phrase）、秘密鍵（Private Key）、機密パスワードをインターネット接続なしに端末内部のみで暗号化して隔離保護する**オンデバイス・ゼロ知識（Zero-Knowledge）セキュリティ金庫モバイルアプリ**です。

暗号資産ウォレット`SeedWallet`の開発中に直面した仮想資産交換業者（VASP）規制の壁を契機に、トランザクションやネットワーク依存を完全に排除。純粋な**ローカル暗号化コア**のみをスピンオフし、**Google Playストアでの正式リリース**を達成しました。

---

## プロジェクトの背景とピボット（Pivot）

### 1. SeedWalletの挫折と規制の壁
当初はクロスチェーン対応や資産管理を包括する次世代ウォレット**SeedWallet**を開発していました。しかし、開発進行に伴い技術外の重大な障害に直面しました:
- 各国の仮想資産サービスプロバイダー（VASP）規制および金融コンプライアンス
- カストディ（保管型）サービスに求められる膨大な監査・法務コスト
- 個人開発の規模を超えた規制遵守リスク

### 2. 価値の再定義：ウォレットから「金庫」へのスピンオフ
プロジェクトを放棄する代わりに、「ユーザーが秘密鍵を外部に一切委ねず最も安全に保管する手段」という本質にフォーカスしました。
- 外部ブロックチェーンノード通信やネットワーク権限をコードベースから全撤廃
- 暗号計算ロジック（`@seedvault/crypto-core`）を独立パッケージとして分離
- 規制リスク皆無の完全オフライン・ユーティリティ**SeedVault**へとピボットし、Google Playへリリース

## 中核セキュリティアーキテクチャ

```
[ Master Password ]
        │
        ▼ (hash-wasm: Argon2id KDF)
[ 256-bit High-Entropy Key ]
        │
        ├── (AES-256-GCM Encryption) ──► [ Encrypted Seed Envelope ]
        │                                  ├── Salt & Nonce/IV
        │                                  ├── Ciphertext
        │                                  └── Auth Tag
        │
        └── (Biometric Hardware Binding) ──► [ Capacitor Secure Storage ]
```

### 1. Argon2id鍵導出（KDF）
- GPU/ASICによる総当たり攻撃を防ぐため、最新のパスワードハッシュ規格である**Argon2id**をWebAssembly（`hash-wasm`）で実行
- モバイル端末の負荷を考慮した最適なメモリコスト・並列度パラメータを設定

### 2. AES-256-GCM 認証付きエンベロープ暗号化
- 機密性と改ざん防止（Integrity）を同時に保証する**AES-256-GCM**を採用
- 暗号文、Salt、IV、Auth Tagを包含する`EncryptedSeedEnvelope`構造を定義し安全にシリアライズ

### 3. 完全なゼロ知識＆ローカルファースト
- バックエンドサーバーの完全排除：情報漏洩やサーバーハッキングのリスクが原理的に存在しません
- 生体認証連携：Capacitor Secure StorageとNative Biometricプラグインを活用し、指紋/Face IDによる迅速なロック解除を実現

### 4. エアギャップ（Air-Gapped）QRバックアップ・復元
- ネットワークを使わずに端末間移行や紙の金庫を作成できるQRバックアップ機構を設計
- EnvelopeデータをZlib（`pako`）圧縮したのち高密度QRコード（`qrcode`）化、カメラ（`jsqr`）で即座に復元
